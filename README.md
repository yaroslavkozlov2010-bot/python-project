# 1. Касса для шаурмы

Простая консольная программа для приёма заказов.

## Как запустить
1. Установи Python 3.
2. Скачай `kacca.py`.
3. Запусти: `python kacca.py`

## Меню
- 12 видов шаурмы
- Добавление свинины (+10 руб.)
- Сохранение заказов в файл `orders.txt`

## Пример
Введи название шаурмы, добавь свинину, получи чек.

(решил сделать, когда покупал шаурму и подумал, что хочу сделать программу для кассы)

# 2. Калькулятор уравнений 4-й степени

Консольная программа для решения уравнений вида:

**a·x⁴ + b·x³ + c·x² + d·x + e = 0**

Программа использует библиотеку `sympy` для символьного решения и сохраняет историю всех вычислений в файл `answers.txt`.
